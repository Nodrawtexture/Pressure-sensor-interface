# Pressure-sensor-interface
Интерфейсный контроллер для измерительного преобразователя давления PTE5000C-010-M20-C на базе микроконтроллера ATmega-1280-16AU

## ВВЕДЕНИЕ
В данной работе был разработан интерфейсный
контроллер для измерительного преобразователя давления PTE5000C-010-M20-C
на базе микроконтроллера ATmega-1280-16AU. Интерфейсный контроллер 
при поступлении запроса по беспроводному интерфейсу SubGz MBee-868
(протокол SerialStar) и проводному интерфейсу RS-485 (протокол Modbus ASCII)
измерительной сети должен вычислять значение давления на выходе
измерительного преобразователя давления (далее – ИПД) PTE5000C-010-M20-C,
передающего сигнал посредством интерфейса токовая петля 4-20 мА.
Диапазон измерения давления: 0-10 бар. Вычисленное значение давления в
заданном формате протоколов SerialStar и Modbus ASCII передается по
интерфейсу измерительной сети.

## ОПИСАНИЕ МОДЕРНИЗИРУЕМОГО ИЗМЕРИТЕЛЬНОГО ПРЕОБРАЗОВАТЕЛЯ
Датчик PTE5000C-010-M20-C служит для преобразования избыточного
давления. Данный датчик имеет диапазон измерения давления от 0 до 10 бар,
который преобразуется датчиком в унифицированный выходной сигнал 4…20
мА, пропорциональный диапазону измерения. Класс точности датчика составляет
0,5%. Преобразование давления в выходной аналоговый сигнал выполняется
непрерывно.

Принцип действия датчика основан на использовании зависимости между
измеряемым давлением и упругой деформацией чувствительного элемента.
В качестве чувствительного элемента применяется керамическая мембрана,
на которой закреплены тензорезисторы, объединенные в мостовую схему
включения. Под воздействием измеряемого давления происходит деформация
мембраны, приводящая к изменению сопротивлений тензорезисторов и
изменению напряжения в узлах мостовой схемы, пропорционально изменению
давления среды. В свою очередь, напряжение преобразуется схемотехникой
датчика в унифицированный аналоговый выходной сигнал 4...20 мА,
пропорциональный диапазону измерения.

## ОПИСАНИЕ РАБОТЫ ИНТЕРФЕЙСНОГО КОНТРОЛЛЕРА ПО ФУНКЦИОНАЛЬНОЙ СХЕМЕ
Данная схема рассчитана на работу от источника питания 24 В. Схема
питания интерфейсного контроллера имеет разделение на два цифровых питания
– 5 В и 3.3 В для нормальной работы компонентов, требующих соответствующее
напряжение. 

К интерфейсному контроллеру подключен ИПД PTE5000C-010-
M20-C. Для преобразования выходного сигнала ИПД токовой петли 4-20 мА в
напряжение в диапазоне 0,4-2 В используется прецизионный резистор 100 Ом,
имеющий погрешность 0,01%. 

Напряжение фильтруется при помощи фильтра
нижних частот. После фильтрации, полученное чистое напряжение подается на
24-разрядный аналого-цифровой преобразователь (далее – АЦП), который
преобразует значения напряжения в код. АЦП питается от двух напряжений – 3.3
В цифрового питания и 3.3 В аналогового питания. 

Цифровое питание подается непосредственно со схемы питания, а аналоговое
питание преобразуется из цифрового при помощи ферритовой бусины. Так как напряжения питания у АЦП
и микроконтроллера различны (3.3 В и 5 В), был применен преобразователь
логических уровней между АЦП и микроконтроллером (далее – МК). 

Схема управления включает в себя МК и разъемы внутрисхемного программирования.
Для организации обмена МК с устройствами, подключенными через интерфейс
RS-485 по протоколу Modbus ASCII, применяется изолирующий приемопередатчик интерфейса RS-485 со встроенным DC-DC преобразователем. 

Для реализации беспроводной связи применен радиомодуль MBee-868-2.0-SMAPLS12 (далее – MBee), который принимает данные со стороны МК при помощи
протокола Modbus ASCII. Полученные данные в формате Modbus ASCII затем
преобразуются модулем MBee в формат протокола SerialStar. Аналогично, как и с
АЦП, для согласования уровней между МК и MBee был применен
преобразователь логических уровней.

При поступлении сообщения из сети измерительного интерфейса о
необходимости передачи измеренного значения давления МК посылает АЦП
запрос посредством интерфейса SPI на передачу результата последнего
преобразования. 

АЦП по умолчанию функционирует в режиме непрерывного
аналого-цифрового преобразования. Максимальная длительность интервала
между сообщениями не была установлена. Было решено, что максимальное время
ожидания ответа на сообщение как минимум равно 1 с. По окончании
преобразования АЦП значения напряжения в код, МК делает запрос на передачу
этого значения. 

Полученный код с АЦП подвергается математическому
преобразованию в значения давления, которые в дальнейшем записываются в
сообщение формата Modbus ASCII и отправляются другим устройствам через
интерфейсы RS-485 и SubGz MBee-868 при помощи UART.
